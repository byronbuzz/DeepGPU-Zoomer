# Code of Conduct

DeepGPU Zoomer welcomes constructive participation from people of all backgrounds and experience levels.

## Expected conduct

Be respectful, patient and precise. Critique ideas and code rather than people. Assume good faith, accept corrections, and help make discussions accessible to newcomers.

Harassment, discrimination, threats, personal attacks, deliberate disruption and publishing someone else's private information without permission are not acceptable.

## Scope and reporting

This applies to project issues, pull requests, discussions and other official project spaces.

To report misconduct, contact the repository maintainer privately through their GitHub profile rather than posting personal or sensitive details publicly. If private contact is unavailable, use GitHub's abuse-reporting mechanism. Reports will be considered confidentially as far as practicable, with action proportionate to the circumstances, including moderation or exclusion from project spaces. No guaranteed response time is promised.

Maintainers are responsible for applying these expectations fairly.
