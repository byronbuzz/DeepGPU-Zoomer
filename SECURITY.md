# Security policy

## Supported versions

Security fixes are considered for the current version on the `main` branch. Older snapshots, forks and unrelated deployments are not maintained by this project.

## Reporting vulnerabilities

**Do not open a public issue containing an unpatched vulnerability, working exploit or sensitive information.** Use GitHub's **Report a vulnerability** / private vulnerability reporting feature if it is enabled for this repository. Otherwise contact the repository owner privately using the contact method on their GitHub profile. If neither option is available, do not publish exploit details; request a private contact channel without including vulnerability details.

Include a concise description, reproduction steps, potential impact, affected version/commit and suggested mitigation if known. Please allow reasonable time for investigation and coordinated disclosure. No fixed response or remediation time is guaranteed.

## Scope

DeepGPU Zoomer is a client-side WebGPU application published as a static site. Reports about its own source, bundled dependencies, client-side data handling and deployment are in scope. Browser, driver and GPU vulnerabilities should also be reported to their respective vendors.

Never include credentials, private saved locations or other users' data in reports.
